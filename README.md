# Geometric-Spectral Framework for the Riemann Hypothesis

**Status: Completed**

**[`publication.md`](publication.md)** — *Geometric Dynamical Phase Transitions and the Spectral Measure of the Riemann Zeros*

The same geometric balance forces every zero onto the critical line.
